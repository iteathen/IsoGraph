# Primitive natural-number and arithmetic theory 0.1

**Status:** unqualified primitive-logic supporting theory  
**Purpose:** remove opaque arithmetic operators from P-vs-NP renderings

## Raw carrier

Only these are raw data:

- carrier `NAT`;
- object `ZERO`;
- constructor tag `SUCC`;
- predecessor field incidence.

Every natural object is generated by `ZERO` and repeated `SUCC`.

## Logical carrier axioms

For every `n` in `NAT`:

```text
n = ZERO
OR
exists p in NAT:
    TAG(n,SUCC)
    AND FIELD(n,PRED,p).
```

`ZERO` is not tagged `SUCC`.

Successor is functional and injective.

Induction is represented as the logical schema:

```text
for every predicate Phi on NAT:

Phi(ZERO)
AND
forall n,p:
    SUCC_OF(n,p)
    AND Phi(p)
      -> Phi(n)

->
forall n:
    Phi(n).
```

No arithmetic operation is primitive.

## Addition

`ADD(a,b,c)` is defined by:

```text
ADD(ZERO,b,b)

and

SUCC_OF(a,a0)
AND
SUCC_OF(c,c0)
->
[ ADD(a,b,c) IFF ADD(a0,b,c0) ].
```

Equivalent constructive reading:

```text
0 + b = b
S(a0) + b = S(c0) iff a0 + b = c0.
```

## Multiplication

```text
MUL(ZERO,b,ZERO)

MUL(S(a),b,c)
IFF
exists d:
    MUL(a,b,d)
    AND ADD(d,b,c).
```

## Power

Let `ONE = SUCC(ZERO)`.

```text
POW(a,ZERO,ONE)

POW(a,S(k),c)
IFF
exists d:
    POW(a,k,d)
    AND MUL(d,a,c).
```

## Order

```text
LE(a,b)
IFF
exists d:
    ADD(a,d,b).
```

Strict order may be derived as:

```text
LT(a,b)
IFF
LE(S(a),b).
```

## Big-O

For unary natural functions `f,g`:

```text
IN_O(f,g)
IFF
exists c,n0:
    forall n:
        LE(n0,n)
        ->
        exists fn,gn,p:
            APPLY(f,n,fn)
            AND APPLY(g,n,gn)
            AND MUL(c,gn,p)
            AND LE(fn,p).
```

## Polynomial growth

```text
IN_O_POLY(f)
IFF
exists k:
    exists powFn:
        forall n,p:
            APPLY(powFn,n,p)
            IFF POW(n,k,p)
        AND IN_O(f,powFn).
```

## Monotonicity

```text
MONOTONIC(f)
IFF
forall x,x',fx,fx':
    LE(x,x')
    AND APPLY(f,x,fx)
    AND APPLY(f,x',fx')
      ->
    LE(fx,fx').
```

These names are derived-view handles only. Their semantic support is the displayed primitive logic.
