# Unification Synthesis Protocol 0.1

**Status:** CURRENT CONSTRUCTIVE-UNIFICATION RESEARCH PROTOCOL  
**Inputs:** independent Woit and Lisi source tracks + frozen common-kernel evidence  
**Authority:** research method only; not IsoGraph semantic authority

## 1. Four surfaces

The campaign now has four logically separate surfaces:

- W — source-faithful Woit treatment;
- L — source-faithful Lisi treatment;
- K — common structure surviving source mapping, closure, residual accounting, and falsifiers;
- U — project-generated unification synthesis.

Information flow during source closure is one-way:

~~~text
W -> K <- L
     |
     v
     U
~~~

No U hypothesis may flow backward to repair W or L.

## 2. Conservative-amalgam rule

Do not define U as all Woit structure plus all Lisi structure.

Begin with K and attach residuals through explicit ports.

Every edge in U has one of four dispositions:

1. INHERITED_W;
2. INHERITED_L;
3. FORCED_BY_K;
4. SYNTHESIS_HYPOTHESIS.

No silent fifth category is allowed.

## 3. Reconstruction diagrams

For every U candidate preserve source reconstruction.

At minimum:

~~~text
W_selected -> U -> W_view
L_selected -> U -> L_view
~~~

must recover the declared source-semantic view.

Where prior comparison provides only quotient maps, choose an explicit comparison realization Kc and preserve the representation maps instead of claiming an unproved categorical pushout.

## 4. Residual classes

Before attachment classify residuals as:

- COMPATIBLE_EXTENSION;
- INTERACTION_CANDIDATE;
- ROLE_CONFLICT;
- REPRESENTATION_ONLY;
- QU;
- OBSTRUCTION.

## 5. Minimal-new-axiom discipline

Use no new relation when an inherited or K-forced relation suffices.

Every new relation records:

~~~text
synthesis ID
source endpoints
exact new relation
why neither source implies it
what it enables
falsifier
what disappears if removed.
~~~

## 6. First attachment program

### U1-TC — twistor/Clifford amalgam

Attach from W:
- global projective/twistor geometry;
- pseudoreal structure;
- chiral Spin(4) geometry.

Attach from L:
- sign-correct chiral Clifford structure;
- division-algebra/triality structure only where exact extension maps exist.

Required tests:
1. local restriction returns K;
2. chart changes preserve the attached algebraic action;
3. W pseudoreal/projective structure is preserved;
4. no unsupported global Lisi structure is invented at the compactification patch;
5. source residuals reconstruct.

### U2-DYN — chiral dynamics amalgam

Inputs:
- W02 self-dual Yang–Mills;
- W02 chiral GR;
- L02 gauge/gravity/Higgs connection;
- L06 generalized-Cartan/deforming-group geometry.

Search for one connection/action architecture whose source projections reconstruct both selected dynamical formulations without identifying distinct fields merely because they occupy analogous roles.

### U3-OT — octonionic/triality extension

Use B05 only after U1 has a stable quaternionic geometry.

Ask whether an octonionic/triality layer preserves lower U0/U1 reconstruction.

### U4-EX — exceptional realization

Test exceptional structure only as a realization of a previously qualified U candidate.

Do not use E8 to define the unification problem.

## 7. Failure modes

Reject or branch a U candidate when:
- a source can no longer reconstruct;
- an inherited source limitation is violated;
- a source role changes without an explicit transition;
- QU is silently resolved;
- an attachment depends on one coordinate presentation but not an equivalent same-author formulation;
- a high-level label is doing work absent from primitive relations.

## 8. Promotion vocabulary

Use only:

- EXPLORATORY_SYNTHESIS;
- STRUCTURALLY_CONSISTENT_CANDIDATE;
- SOURCE_RECONSTRUCTIVE_CANDIDATE;
- POSTSEAL_QUALIFIED_UNIFICATION_CANDIDATE;
- REJECTED.

Do not use "unified theory" as an unqualified success label before post-seal review and physical-evidence boundaries are explicit.
