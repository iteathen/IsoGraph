# Primitive Dimension-8 Basis Schema 0.1

**Status:** RESEARCH-LOCAL FINITE-BASIS SUPPORT  
**Native:** `PRIMITIVE_DIMENSION_8_SCHEMA_0_1.isg`

## 215000

215000 represents an exact eight-element basis over an already rendered field/vector-space interface.

It requires:

- all eight basis values belong to the vector carrier;
- if an eight-term linear combination is zero, all eight coefficients are zero;
- every vector has an eight-term expansion in the represented basis.

The eight-term sum is represented by an explicit balanced tree of ordinary vector-addition incidences. No dimension label or cardinality primitive is imported.

This schema is domain-neutral. It does not assert octonions, spinors, Clifford structure, topology, or a source interpretation.
