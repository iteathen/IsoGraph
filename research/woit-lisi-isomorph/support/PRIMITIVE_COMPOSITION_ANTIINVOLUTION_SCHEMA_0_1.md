# Primitive Composition-Algebra Anti-Involution Schema 0.1

**Status:** RESEARCH-LOCAL COMPOSITION SUPPORT  
**Native:** `PRIMITIVE_COMPOSITION_ANTIINVOLUTION_SCHEMA_0_1.isg`

## 215001

215001 represents a linear involution KAPPA on a unital composition algebra that:

- fixes the unit;
- squares to identity;
- reverses multiplication order, KAPPA(xy)=KAPPA(y)KAPPA(x);
- preserves the represented composition norm.

It depends on composition-algebra schema 185003 rather than associative-algebra schema 185001.

Therefore it is valid for nonassociative composition-algebra instances such as octonionic source carriers and does not silently import associativity.

This is algebra conjugation only. It is not complex conjugation, Hermitian adjoint, source real structure, or projective pseudoreality unless separately instantiated.
