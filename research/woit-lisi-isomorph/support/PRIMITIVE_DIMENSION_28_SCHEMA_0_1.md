# Primitive Dimension-28 Basis Schema 0.1

**Status:** RESEARCH-LOCAL FINITE-BASIS SUPPORT  
**Native:** `PRIMITIVE_DIMENSION_28_SCHEMA_0_1.isg`

## 225001

225001 represents an exact 28-element basis of an already-rendered vector space.

It expands the statement into primitive structure:

- all 28 supplied values belong to the vector carrier;
- an explicit 28-term linear combination can equal zero only when all 28 scalar coefficients are zero;
- every represented vector is an explicit 28-term linear combination of the supplied basis values.

The 28-term combination is built only from the existing scalar action and ordinary vector addition. No dimension/cardinality label is left as a semantic leaf.

The schema is domain-neutral. It contains no bivector, Lie, Spin, triality, matrix, root-system, or physical interpretation.
