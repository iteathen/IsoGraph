# Primitive Exact Dimension-7 / Dimension-28 Basis Schemas 0.1

**Status:** RESEARCH-LOCAL FINITE-BASIS SUPPORT  
**Native files:** `PRIMITIVE_DIMENSION_7_SCHEMA_0_1.isg`, `PRIMITIVE_DIMENSION_28_SCHEMA_0_1.isg`

## 225000

Represents an exact seven-dimensional vector space through:

- seven explicit basis values;
- linear independence;
- spanning.

## 225001

Represents an exact twenty-eight-dimensional vector space through:

- twenty-eight explicit basis values;
- linear independence;
- spanning.

Both schemas expand finite linear combinations using explicit scalar-multiplication and vector-addition incidences. Neither attaches geometric, Lie-algebra, octonionic, Clifford, or physical semantics to the basis.

They are generic finite-basis support for source-local reconstructions.
