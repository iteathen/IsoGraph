# Primitive Linear Injection Schema 0.1

**Status:** RESEARCH-LOCAL REPRESENTATION SUPPORT  
**Native:** PRIMITIVE_LINEAR_INJECTION_SCHEMA_0_1.isg

193400 requires a total linear map F:A->B and injectivity.

It does not require surjectivity.

This is used when a source real form/subcarrier embeds into a larger complexified carrier, such as Woit's Euclidean four-vector space inside M(2,C)=Hom(S_R,S_L).
