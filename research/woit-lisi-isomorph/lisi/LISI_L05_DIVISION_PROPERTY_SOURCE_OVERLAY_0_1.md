# L05 Division Property Source Overlay 0.1

**Status:** SOURCE-LOCAL DIVISION-ALGEBRA CLASSIFICATION / PRE-SEAL  
**Native:** `LISI_L05_DIVISION_PROPERTY_SOURCE_OVERLAY_0_1.isg`

L05 classifies C, H, and O as division algebras and C′, H′, O′ as split composition algebras.

This file expands the **division** half of that classification through exact schema 216003 for:

- ordinary complex C;
- quaternion H;
- ordinary octonion O.

The split carriers are intentionally not given 216003.

The ordinary-O source table remains internally inconsistent with other source claims; this overlay preserves the source division assertion rather than silently repairing its multiplication table.
