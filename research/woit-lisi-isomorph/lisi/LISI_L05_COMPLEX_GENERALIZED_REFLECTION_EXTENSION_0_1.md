## Reduction

A time-like odd reflection is not treated as one opaque map.

For each split family C', H', O', it is decomposed into three parameterized linear component maps.

Example: a vector-directed reflection consists of:

~~~text
V_C -> V_C
P_C -> M_C
M_C -> P_C
~~~

for a fixed negative-norm vector direction.

Each component is first pinned on the embedded real source carrier by the authoritative 229xxx time-like formulas.

Generic schema `231000` then supplies the unique represented complex-linear extension over the exact finite scalar-extension carrier.

## Complex-domain anti-invariance

For every admissible complexified input triple:

~~~text
T_C(R_u(v,m,p)) = -T_C(v,m,p).
~~~

This is not inferred from a name. It is explicitly represented over the scalar-extended triality relation and the complex-linear reflection maps.

## Even compositions

~~~text
T_C(R_2(R_1(v,m,p))) = T_C(v,m,p).
~~~

The composition relation is explicit and includes the intermediate complexified triple.
