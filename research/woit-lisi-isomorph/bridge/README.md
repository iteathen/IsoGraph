## Current candidates

### B01 — chiral action / incidence
Weak form:
- vector-like carrier V;
- graded spinor carrier S = S+ + S-;
- bilinear action V x S -> S;
- action exchanges S+ and S-.

Strong refinement:
- the action also satisfies the represented Clifford square relation.

This is designed to expose the common core below named twistors, Clifford algebras, or triality.

### B02 — parametrized projective incidence
- projective quotient of a vector carrier;
- represented family of linear subspaces;
- projective incidence;
- another carrier parametrizes the subspace family.

Dimension-specific CP3/CP1 statements remain residual until represented.

### B03 — graded real structure
Base:
- complex/algebraic scalar conjugation;
- antilinear involution J;
- chiral grading CHI;
- fixed-point real carrier.

Two refinements are preserved separately:
- J commutes with CHI;
- J anticommutes with CHI and exchanges chirality.

No choice is forced before source instantiation.

### B04 — parent-selection transition
DTS-shaped template:
- a larger parent structure is preserved;
- a previously fundamental external/base choice is removed or demoted;
- an internal selection/embedding structure is introduced;
- a physical spacetime-facing structure is recovered/selected;
- unresolved mechanism stays QU-bearing.

No Transition Isomorph claim is made.
