## 4. Complete Source Semantic Census

The SSC is broader than proposition-shaped claims. For every frozen source, census at least explicit assertions, definitions, carrier/domain choices, dimensions/signatures, real/complex structures, operator/relation semantics, representation actions, subgroup/subalgebra/embedding claims, quotient/projective/incidence structure, bundle/connection/curvature structure, transition/revision/symmetry-breaking semantics, quantization/dynamics claims, side conditions, negative claims, limitations, unresolved questions, source-native cross references, and revisions of earlier formulations.

A source section can be marked fully traversed only when every load-bearing semantic item has a census disposition.

## 5. Primitive closure

Named mathematics is never accepted as an opaque semantic leaf merely because it is standard.

Illustrative non-primitive labels include real numbers, complex numbers, vector space, linear map, bilinear/Hermitian form, conjugation, graded/chiral space, Clifford algebra, spin group, spinor representation, Lie group/algebra, representation, embedding, projective space, twistor, incidence relation, principal bundle, Cartan geometry, connection, curvature, differential form, Hodge dual, triality, division algebra, magic-square algebra, root system, gauge field, Higgs field, fermion generation, and Wick rotation.

Each load-bearing occurrence must reduce to primitive relational/logical support or an exact closed schema.

### 5.1 Schema closure is expected

Continuous/infinite mathematical structures should normally use Core-0.21 Schema Closure rather than extensional materialization.

For example, an abstract field is represented by a carrier predicate, total operation graphs, distinguished values, field axioms reduced to quantified primitive logic, and any additional order/conjugation/completeness structure required by the source claim. FIELD remains a derived view.

### 5.2 Missing definition is not QU

If the renderer has not yet represented the semantics of a load-bearing mathematical term, the item is INCOMPLETE_UNEXPANDED, not a QU boundary. QU is reserved for genuinely unresolved source/domain realization under qualified QU semantics.

## 6. Native graph authority
