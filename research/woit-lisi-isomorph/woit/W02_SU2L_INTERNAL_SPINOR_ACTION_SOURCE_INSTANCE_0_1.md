## Nontrivial internal witness

The source matrix element 205150 = -i sigma1 belongs to the same exact special-unitary matrix group underlying both Euclidean factor roles.

Its S_L action is pinned:

```text
205150 . l1 = -i l2
```

and the result is explicitly distinct from l1.

Thus SU(2)_L has a nontrivial action on the left-spinor carrier.

## Spacetime contrast

The existing corrected right-handed Euclidean source instance gives the same SU(2)_L role an exact trivial action on the Euclidean spacetime carrier.

The pair of facts

```text
SU(2)_L action on spacetime: trivial
SU(2)_L action on S_L:      nontrivial
```

is the source-local structural meaning of the internal-vs-spacetime role distinction used here.
