## Correction

The source matrix algebra defines `204116=I` and `204120=E22`.

Revision 0.1 incorrectly supplied 204120 as the identity element when instantiating the SL(2,C)_R and SU(2) group/action schemas.

Revision 0.2 replaces those group/action identity parameters by 204116.

The separate source equation

```text
i * E22 = ...
```

continues to use 204120 as the matrix unit E22 and is unchanged.
