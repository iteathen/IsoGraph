# Woit-local Conjugate-Semilinear Vector Bijection Schema 0.1

**Status:** W-TRACK RESEARCH-LOCAL REUSABLE SUPPORT  
**Native:** `WOIT_PRIMITIVE_CONJUGATE_VECTOR_BIJECTION_SCHEMA_0_1.isg`

Schema 944000 represents a conjugate-semilinear bijection between two vector spaces over the same complex field.

It requires:

- exact scalar conjugation through schema 183001;
- exact vector-space structures on source and target;
- a true bijection through schema 188100;
- zero preservation;
- additive preservation;
- twisted scalar compatibility
  `H(a v)=conj(a) H(v)`.

This supplies the missing generic notion of a conjugate vector-space presentation without introducing “conjugate spinor” as an opaque leaf.

It does not assert a group-representation intertwiner. That is a separate burden when representation equivalence is load-bearing.
