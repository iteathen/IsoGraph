# Woit-local Dual Pairing Schema 0.1

**Status:** W-TRACK RESEARCH-LOCAL REUSABLE SUPPORT  
**Native:** `WOIT_PRIMITIVE_DUAL_PAIRING_SCHEMA_0_1.isg`

Schema 947000 gives an exact algebraic dual-pairing interface between two vector spaces over the same field.

It requires:

- exact vector-space structure on a primal carrier (V);
- exact vector-space structure on a dual carrier (D);
- a total scalar-valued pairing (D x V -> C);
- additivity and scalar linearity in both arguments;
- nondegeneracy in both arguments.

This is the minimum load-bearing behavior needed for source statements using “dual spinor”; the dual role is not accepted as a name-only node.

The schema does not assert topology, continuity, inner products, conjugate-linearity, or any canonical identification (V\cong D).
