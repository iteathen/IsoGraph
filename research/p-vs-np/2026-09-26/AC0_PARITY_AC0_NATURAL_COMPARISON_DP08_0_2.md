## 1. The barrier attaches to a derived property, not proof syntax

The exact barrier source makes the trigger:

```text
exists Phi such that
    usefulness
    AND largeness
    AND AC0 constructivity
```

with parameters matched by a PRF.

Thus:

```text
remove an explicit "natural property" node
from a proof presentation
    !=
escape the barrier
```

if an equivalent or slightly modified proof can still yield such a Phi.

This is load-bearing for IsoGraph because the barrier is effectively defined over a **naturalization closure of proof presentations**, not over one literal source graph.

## 2. First exact consumer of switching structure in the naturalization

For the switching proof, the source extracts:

```text
Phi(f) =
    f is nonconstant on every Boolean subcube
    of the selected dimension.
```

The Switching Lemma supplies **usefulness**:

```text
easy depth-d size-S f
    -> has a monochromatic large subcube
    -> Phi(f)=0
```

The random-function counting argument supplies **largeness**.

A direct truth-table AC0 test supplies **constructivity**.

Therefore the barrier signature is not generated by the switching lemma alone.

It is generated by the conjunction:

```text
switching simplification
+ generic robust target property
+ random largeness
+ cheap truth-table recognizability
```

This is the first exact decomposition of the barrier trigger in this campaign.

## 3. PARITY-specific semantics are not the load-bearing barrier trigger

The formal Lean proof carries parity-specific structure:

```text
parity under restriction
+ offset
+ narrow-DNF disagreement with parity/complement
```

But the naturalized proof presented by the 2026 source replaces the target-specific terminal condition with a broader one:

```text
nonconstant on every sufficiently large subcube
```

PARITY is only one function satisfying that property.

Therefore:

```text
parity-specific terminal semantics
    are sufficient for the formal proof

but
    are not uniquely necessary
for the naturalized lower-bound argument.
```

This is source-backed rather than a new theorem.

It has an important barrier consequence: making a prospective proof look more target-specific does not by itself make it non-natural if a generic large/constructive property can still be extracted.

## 4. Barrier escape requires breaking the extracted bundle, not merely a local lemma

For the exact Definition 2.3 trigger, at least one of the following must fail at the target parameters:

```text
U — usefulness
L — largeness
C — constructivity
```

or the matching PRF premise must fail.

A proposed alternative proof that preserves a naturalized `(U,L,C)` bundle remains inside the barrier even if its internal lower-bound lemmas differ radically.

Thus the meaningful barrier signature is:

```text
B = (U,L,C,PRF-parameter match)
```

not:

```text
B = names of proof techniques used.
```

## 5. Naturalization is an alternate-factorization operator

This is structurally analogous to other IsoGraph alternative-factorization results.

One proof presentation may contain target-specific machinery, while an alternate presentation/extraction yields:

```text
target-specific proof
    ->
generic truth-table property
    ->
same lower-bound conclusion
```

The barrier theorem consumes the generic property.

Therefore minimum-support analysis of only the original proof graph is insufficient to establish barrier escape.

A correct search space must include known naturalization transforms.

### Consequence

```text
minimal proof support
    !=
minimal barrier-trigger support
```

and:

```text
proof lacks explicit barrier witness
    !=
barrier witness absent from its naturalization closure.
```

This is the main new IsoGraph representation consequence of the exact barrier rendering.

It is not claimed as a new complexity-theory theorem.

## 6. The previous depth-role split is orthogonal to the barrier trigger

The prior PARITY DP pass split depth into:

```text
D_switch
D_unfold
```

Removing `D_unfold` through a DAG-native lower-bound proof could improve quantitative support.

But if the result still proves usefulness of an AC0-constructive large property, then:

```text
B = natural
```

remains unchanged.

Similarly, improving the switching collapse while preserving the same extracted anti-subcube property can improve theorem strength without changing the barrier signature.

## 7. A sharper future discovery target

Instead of asking:

```text
how can switching be stronger?
```

ask:

```text
which successful lower-bound invariant is useful
but cannot be naturalized into a simultaneously
large and AC0-constructive property
at the required parameters?
```

This is a significantly narrower structural question.

It points toward comparing:

1. AC0-natural switching proofs;
2. the paper's few lower-bound proofs it could not naturalize;
3. nonrelativizing-but-algebrizing proofs;
4. top-down lower-bound arguments with different truth-table property structure.

The source itself warns that failure to find a naturalization is not proof of non-naturality. Such cases remain QU.

## 8. Falsifiers for candidate barrier escape

A candidate is **not** evidence of barrier escape merely because:

- it avoids the literal Switching Lemma theorem;
- it uses a target-specific invariant;
- it bypasses circuit-to-formula unfolding;
- it improves an exponent;
- its explicit proof text never constructs Phi;
- it uses a different restriction distribution.

A candidate becomes barrier-relevant only if the naturalization audit changes one of:

```text
usefulness
largeness
constructivity
PRF parameter matching
```

with the lower-bound objective preserved.

## 9. Current result

No barrier escape has been found.

No P-vs-NP theorem has been found.

What has closed is the representation question:

```text
AC0-natural barrier trigger

```

This gives the campaign a precise next search space rather than a vague instruction to “beat the switching lemma.”

## 10. Highest-value next lead

The 2026 paper reports a small number of top-down AC0 lower-bound proofs for which the authors did not find AC0-natural variants.

Those are the highest-value next controls because they sit directly on the known/unknown boundary of the barrier signature.

Procedure:

1. select one such proof;
2. freeze its original theorem/source;
3. exact-render its lower-bound mechanism;
4. render the paper's attempted/naturalized neighboring proof if available;
5. ask DP which support relation prevents the known naturalization;
6. keep the conclusion QU unless non-naturalizability itself is proved.

This is more informative than immediately attempting unrestricted SAT circuit lower bounds.
