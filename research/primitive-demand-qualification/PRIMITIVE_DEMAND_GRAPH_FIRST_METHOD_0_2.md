# Primitive Demand Graph-First Method 0.2

**Status:** research procedure candidate; not semantic authority  
**Date:** 2026-10-06  
**Predecessor evidence:** `DEMAND_EXTRACTION_RULES_0_1.json`, `PRIMITIVE_DEMAND_GRAPH_0_1.json`, `CANDIDATE_PRIMITIVE_BASIS_0_1.json`  
**Regrounding audit:** `PRIMITIVE_DEMAND_REGROUNDING_AUDIT_0_1.json`

## Purpose

This procedure inserts the missing graph-first stage between the frozen unresolved W/L source bodies and any candidate primitive or reusable schema.

The controlling rule is:

```text
source body
  -> source-conserved semantic occurrence graph
  -> qualified-Core definability marking
  -> alpha-renamed structural quotient
  -> candidate basis synthesis
  -> independent qualification
```

Candidate primitive/schema classes MUST NOT be named, selected, or attached to source bodies before the structural quotient exists.

## G0 — freeze the unresolved corpus and authority

Inputs are exactly:

- the 84 unresolved W bodies pinned by `SOURCE_DEMAND_CENSUS_0_1.json`;
- the 151 unresolved L bodies pinned by the same census;
- exact qualified cumulative Core through Core 0.21;
- qualified QU only when a frozen source body itself contains genuinely unresolved structured possibility.

No W body may premise an L body and no L body may premise a W body.

Historical boundary categories, regex demand rules, DNWF, bridge candidates, and prior candidate basis labels are unavailable as semantic premises.

## G1 — semantic occurrence census

For every frozen body, create a complete occurrence census of each load-bearing semantic operation/relation whose behavior is not already supplied by qualified Core.

Each occurrence record must preserve:

- source census ID;
- exact source span or an exact reversible body reference;
- occurrence identity;
- explicit argument/result roles when stated;
- variable/binder ownership when stated;
- logical connective/quantifier incidence;
- dependency on other occurrences in the same body;
- source side conditions and modality;
- whether the occurrence is only an opaque referent or whether its behavior is load-bearing.

At this stage:

- preserve source-domain words for provenance only;
- do not map a word such as “bundle,” “group,” “Hodge,” “Penrose,” “triality,” or “quotient” to a primitive class;
- do not infer cross-track equivalence;
- do not attach a `requires` list of candidate basis IDs;
- do not declare a new primitive.

An occurrence whose semantic boundary cannot be extracted without interpretation remains explicitly `OCCURRENCE_EXTRACTION_INCOMPLETE`; it is not silently categorized.

## G2 — neutral occurrence graph

Compile the occurrence census using only:

- qualified Core logical operations;
- exact binding and ordered-incidence structure;
- raw carrier/value identities where behavior is not hidden in the atom;
- fresh opaque identities for unresolved semantic occurrences;
- explicit `UNEXPANDED_SEMANTIC_OCCURRENCE` research-state markers.

The marker is bookkeeping only. It is not a Core primitive and cannot close an SSC item.

Every graph edge must descend from a frozen source occurrence. No category node may be inserted merely because conventional mathematics suggests it.

## G3 — qualified-Core definability pass

For each unresolved occurrence, ask only:

1. Is its full load-bearing behavior already expressed by qualified Core logic/incidence plus represented raw data?
2. Does an exact recoverable lower definition exist under qualified authority?
3. Can a finite Core-0.21 schema express all-and-only the required generated family without adding semantic authority?
4. Is the source meaning itself genuinely unresolved and therefore lawfully QU-bearing?
5. Otherwise, what exact semantic behavior remains unexpanded?

The output is one of:

```text
CORE_CLOSED
CORE_SCHEMA_CANDIDATE_PENDING_QUALIFICATION
QUALIFIED_QU_BOUNDARY_CANDIDATE
UNEXPANDED_DEMAND
```

A familiar mathematical definition may be used only after its exact semantics have been represented and source fidelity has been established. Familiarity is not authority.

## G4 — structural quotient

Only `UNEXPANDED_DEMAND` subgraphs enter primitive-demand quotienting.

Before comparison:

- replace source referent identities by fresh local variables;
- retain node/edge roles, arity, binding, direction, multiplicity, logical polarity, dependency incidence, side-condition placement, and closure obligations;
- retain distinctions whose deletion changes exact reconstruction.

Two demands may enter the same quotient class only when their neutral graphs are isomorphic under alpha-renaming for the declared comparison scope.

Forbidden quotient evidence:

- shared source-domain noun;
- shared conventional mathematical category;
- regex co-match;
- historical bridge hypothesis;
- desired unification outcome;
- prior candidate-basis membership.

Cross-track support is useful only after the quotient is independently obtained.

## G5 — candidate basis synthesis

Candidate basis synthesis occurs after G4.

For each quotient class:

1. attempt reduction using qualified Core and already qualified generic modules;
2. identify the smallest residual semantic behavior not so reducible;
3. test whether one residual candidate covers several quotient classes by explicit reconstruction;
4. preserve non-covered residuals rather than enlarging a candidate by intuition;
5. minimize only relative to the frozen graph and declared dependency model.

A candidate may be:

- a pure Core schema requiring no new semantic authority;
- a separately qualified generic module;
- a proposed semantic extension when irreducible behavior is actually demonstrated;
- an unresolved boundary.

No candidate becomes authority by being minimal or cross-track.

## G6 — independent qualification

Every proposed reusable module/extension must run as its own IsoGraph project:

```text
freeze module SSC
-> source conservation
-> native primitive/schema closure
-> recursive module-local IA fixed point
-> applicable NEI/DTS/DP only after closure
-> positive + adversarial controls
-> reconstruction + scope + authority-routing qualification
-> promotion review
```

W and L may consume only exact promoted authority.

## G7 — return to source tracks

After a candidate is qualified:

1. reopen only W/L items whose unresolved demand graphs explicitly depend on that authority;
2. compile source-local bodies independently;
3. require exact reconstruction;
4. regenerate graph-derived Core-0.21 ledgers;
5. repeat primitive/schema closure until no reducible open demand remains;
6. only then begin recursive source-local IA.

## Mechanical guards for the 0.2 implementation

A conforming 0.2 extractor/verifier must enforce at least:

- all 235 frozen unresolved bodies are represented exactly once;
- every semantic occurrence has exact source provenance;
- no candidate-basis ID occurs in extraction input or G1/G2 artifacts;
- no `requires` edge to a candidate basis exists before G5;
- no source-domain term participates in quotient keys;
- quotient keys are derived only from canonical neutral graph structure;
- graph generation is deterministic from the frozen occurrence census;
- a failed or incomplete occurrence extraction remains visible;
- changing qualified authority invalidates G3 and every downstream quotient/basis result.

## Current boundary

The existing W/L native graphs do not yet contain the internal incidence required by G1/G2; their unresolved items remain routing shells pointing back to SSC bodies.

Therefore the immediate lawful work is **not** another primitive proposal. It is completion and audit of the 235-body semantic occurrence census. Until that exists, the prior v0.1 demand categories and DNWF path remain diagnostic evidence only.
