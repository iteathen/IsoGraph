# Primitive Demand Graph-First Method 0.3

**Status:** research procedure candidate; not semantic authority  
**Date:** 2026-10-07  
**Predecessor:** `PRIMITIVE_DEMAND_GRAPH_FIRST_METHOD_0_2.md`  
**Reason for successor:** makes hypothesis generation, experimental qualification, scoped authority use, and retained epistemic provenance explicit after a graph-first residual boundary is reached.

## Purpose

This procedure preserves the graph-first discipline of 0.2 while clarifying what happens when exact reduction reaches a residual boundary.

The controlling rule is:

```text
source body
  -> source-conserved semantic occurrence graph
  -> qualified-Core definability marking
  -> alpha-renamed structural quotient
  -> candidate basis synthesis
  -> hypothesis generation where warranted
  -> explicit falsification / qualification
  -> scoped promoted authority with provenance retained
  -> source-track reopening
```

The method permits informed guessing as a discovery operation. It does **not** permit guessing as an authority operation.

The governing distinction is:

```text
hypothesis generation
    != authority

qualification
    -> may grant scoped operational authority

qualification
    != erasure of hypothesis provenance
```

A successful hypothesis may become current authority for the exact scope it has earned. Its record must continue to state that the candidate originated as a hypothesis and how it was tested.

## G0 — freeze the unresolved corpus and authority

Inputs are exactly the frozen unresolved source corpus for the active campaign and the exact authority tuple declared by that campaign.

For the Woit/Lisi campaign this includes the frozen W and L unresolved bodies and exact qualified cumulative Core through Core 0.21, plus qualified QU only when the frozen source itself contains genuinely unresolved structured possibility.

No W body may premise an L body and no L body may premise a W body.

Historical boundary categories, regex demand rules, DNWF, bridge candidates, and prior candidate-basis labels remain unavailable as semantic premises unless independently requalified under the governing authority.

## G1 — semantic occurrence census

For every frozen body, create a complete occurrence census of each load-bearing semantic operation/relation whose behavior is not already supplied by qualified Core.

Each occurrence record must preserve:

- source census ID;
- exact source span or an exact reversible body reference;
- occurrence identity;
- explicit argument/result roles when stated;
- variable/binder ownership when stated;
- logical connective/quantifier incidence;
- dependency on other occurrences in the same body;
- source side conditions and modality;
- whether the occurrence is only an opaque referent or whether its behavior is load-bearing.

At this stage:

- preserve source-domain words for provenance only;
- do not map familiar source terms directly to primitive classes;
- do not infer cross-track equivalence;
- do not attach a `requires` list of candidate basis IDs;
- do not declare a new primitive.

An occurrence whose semantic boundary cannot be extracted without interpretation remains explicitly `OCCURRENCE_EXTRACTION_INCOMPLETE`; it is not silently categorized.

## G2 — neutral occurrence graph

Compile the occurrence census using only:

- qualified Core logical operations;
- exact binding and ordered-incidence structure;
- raw carrier/value identities where behavior is not hidden in the atom;
- fresh opaque identities for unresolved semantic occurrences;
- explicit `UNEXPANDED_SEMANTIC_OCCURRENCE` research-state markers.

The marker is bookkeeping only. It is not a Core primitive and cannot close an SSC item.

Every graph edge must descend from a frozen source occurrence. No category node may be inserted merely because conventional mathematics suggests it.

## G3 — qualified-Core definability pass

For each unresolved occurrence, ask only:

1. Is its full load-bearing behavior already expressed by qualified Core logic/incidence plus represented raw data?
2. Does an exact recoverable lower definition exist under qualified authority?
3. Can a finite Core-0.21 schema express all-and-only the required generated family without adding semantic authority?
4. Is the source meaning itself genuinely unresolved and therefore lawfully QU-bearing?
5. Otherwise, what exact semantic behavior remains unexpanded?

The output is one of:

```text
CORE_CLOSED
CORE_SCHEMA_CANDIDATE_PENDING_QUALIFICATION
QUALIFIED_QU_BOUNDARY_CANDIDATE
UNEXPANDED_DEMAND
```

A familiar mathematical definition may be used only after its exact semantics have been represented and source fidelity has been established. Familiarity is not authority.

## G4 — structural quotient

Only `UNEXPANDED_DEMAND` subgraphs enter primitive-demand quotienting.

Before comparison:

- replace source referent identities by fresh local variables;
- retain node/edge roles, arity, binding, direction, multiplicity, logical polarity, dependency incidence, side-condition placement, and closure obligations;
- retain distinctions whose deletion changes exact reconstruction.

Two demands may enter the same quotient class only when their neutral graphs are isomorphic under alpha-renaming for the declared comparison scope.

Forbidden quotient evidence:

- shared source-domain noun;
- shared conventional mathematical category;
- regex co-match;
- historical bridge hypothesis;
- desired unification outcome;
- prior candidate-basis membership.

Cross-track support is useful only after the quotient is independently obtained and only where the campaign permits cross-track evidence.

## G5 — candidate basis synthesis

Candidate basis synthesis occurs after G4.

For each quotient class:

1. attempt reduction using qualified Core and already qualified generic modules;
2. identify the smallest residual semantic behavior not so reducible;
3. test whether one residual candidate covers several quotient classes by explicit reconstruction;
4. preserve non-covered residuals rather than enlarging a candidate by intuition;
5. minimize only relative to the frozen graph and declared dependency model.

A G5 result may be:

- a pure Core schema requiring no new semantic authority;
- a separately qualified generic module already available for consumption;
- a proposed semantic extension;
- a testable hypothesis candidate;
- an unresolved boundary.

No candidate becomes authority by being minimal, elegant, familiar, recurrent, or cross-track.

### G5 fixed-point interpretation

A G5 fixed point means:

> No further candidate is presently justified by the current deterministic reduction and synthesis pass.

It does **not** mean:

> No lawful discovery strategy remains.

When a material residual remains and current represented reasoning is insufficient, qualified DP 0.10 may support an Experimental Warrant and qualified EI 0.1 may be used to construct and test a provisional working hypothesis, subject to the campaign's anti-bias and information-firewall rules.

## G5H — hypothesis generation and guess-and-test

Hypothesis generation is lawful when it is explicitly separated from authority.

A `HYPOTHESIS_CANDIDATE` may propose, for example:

- a candidate primitive or relation;
- a candidate finite schema;
- a candidate decomposition;
- a candidate hidden incidence;
- a candidate operation law;
- a candidate equivalence/quotient condition;
- a candidate compatibility law;
- another exact structure whose consequences can be tested.

Every such candidate must preserve at least:

```text
origin = HYPOTHESIS
parent residual / quotient class / discovery warrant
candidate statement
declared scope
evidence that motivated the guess
prohibited evidence sources
predicted consequences
known alternatives
positive controls
negative/adversarial controls
falsifiers
adaptive evidence used to select the candidate
fresh or independently fixed confirmation evidence where required
coverage limits
revision lineage
```

The candidate may be generated by mathematical judgment, source-local interpretation, analogy, model construction, or other gap-directed discovery **only when those inputs are lawful for the active campaign**.

For independently sealed source tracks, prohibited cross-track information remains prohibited during hypothesis generation and testing.

The rule is:

> Guess freely inside the lawful evidence boundary; believe only what the tests earn.

A failed hypothesis remains research evidence. It may be revised or rejected, but it is not promoted.

Failure to find a candidate is not proof that the residual is irreducible.

## G6 — independent qualification with retained provenance

Every proposed reusable module/extension or hypothesis-derived authority must run through an explicit qualification project appropriate to the claim.

The default sequence is:

```text
freeze candidate + exact scope
-> freeze qualification questions and falsifiers
-> source/evidence conservation
-> native primitive/schema closure
-> recursive module-local IA fixed point where applicable
-> applicable NEI/DTS/DP only after closure
-> positive controls
-> adversarial/negative controls
-> fresh or independently fixed confirmation where required
-> reconstruction + scope + authority-routing qualification
-> promotion review
```

### G6.1 Authority effect

Before qualification:

```text
HYPOTHESIS_CANDIDATE
    = discovery evidence only
    = not authority
```

After successful qualification and explicit promotion:

```text
qualified exact revision
    = usable authority within its qualified scope
```

The promotion record must preserve the hypothesis origin.

A convenient provenance label is:

```text
HYPOTHESIS_QUALIFIED
```

This label is **qualification/provenance metadata**, not a new Core truth value, primitive, or universal ontology class.

### G6.2 Provenance retention

Promotion must not rewrite the candidate as though it had been:

- directly stated by the original source;
- deductively forced from earlier authority;
- known before the experimental campaign;
- confirmed outside the scope actually tested.

The authority record must retain:

- hypothesis-origin provenance;
- exact candidate revision/hash;
- qualification suite;
- controls and falsifiers;
- adaptive evidence lineage;
- fresh-confirmation status;
- tested/qualified scope;
- known exclusions and unresolved scope;
- downstream dependents.

The governing rule is:

> **Qualification grants scoped authority; qualification does not erase provenance.**

### G6.3 Authority is not a flat equivalence class

A qualified hypothesis may be fully usable for downstream work inside its qualification contract while still differing epistemically from directly inherited or deductively forced authority.

Therefore:

```text
usable authority
    != identical provenance basis

qualified within scope
    != universal truth

strong test coverage
    != source derivation

later stronger grounding
    != permission to erase earlier hypothesis history
```

If later evidence independently derives the same result from stronger authority, the current authority basis may be upgraded or superseded. The provenance chain remains historical evidence.

If a later counterexample falls inside the qualified scope, affected authority must reopen under the applicable invalidation rules.

## G7 — return to source tracks

After a candidate is qualified and promoted:

1. reopen only source items whose unresolved demand graphs explicitly depend on that authority;
2. consume only the exact promoted revision and only within its qualified scope;
3. retain the authority-provenance dependency so downstream claims remain traceable to any hypothesis-qualified ancestor;
4. compile source-local bodies independently;
5. require exact reconstruction;
6. regenerate graph-derived Core-0.21 ledgers;
7. repeat primitive/schema closure until no reducible open demand remains;
8. only then begin recursive source-local IA.

A source track may use `HYPOTHESIS_QUALIFIED` authority exactly as its promotion contract permits. It must not silently relabel that authority as source-inherited or deductively forced.

## Mechanical guards for the 0.3 implementation

A conforming 0.3 implementation must enforce at least:

- every semantic occurrence has exact source provenance;
- no candidate-basis ID occurs in extraction input or G1/G2 artifacts;
- no `requires` edge to a candidate basis exists before G5;
- no source-domain term participates in quotient keys;
- quotient keys are derived only from canonical neutral graph structure;
- graph generation is deterministic from the frozen occurrence census;
- a failed or incomplete occurrence extraction remains visible;
- changing qualified authority invalidates G3 and every downstream quotient/basis result as required by Core 0.21;
- every hypothesis candidate is explicitly non-authoritative before qualification;
- hypothesis-origin provenance survives successful promotion;
- adaptive evidence used for hypothesis selection is not silently counted as untouched confirmation;
- failed hypotheses remain visible as negative evidence;
- downstream consumption of a hypothesis-qualified result is scope-checked and provenance-traceable.

## Relationship to qualified DP 0.10 and EI 0.1

This research procedure does not modify the semantics of the already-qualified DP 0.10 or EI 0.1 artifacts.

It applies them as follows:

```text
residual boundary
-> DP 0.10 asks whether new observation is warranted
-> EI 0.1 constructs/revises a provisional working model and experiments
-> observations return as evidence
-> qualification project tests the exact candidate
-> promotion, if earned, grants scoped authority with provenance retained
```

No change to the current qualified IsoGraph family is claimed by this document.

## Working summary

```text
Reduce mechanically as far as current authority allows.

If a material residual remains:
    do not promote the residual by default
    do not stop merely because deduction ran out

Instead:
    generate a lawful hypothesis
    state what it predicts
    try to falsify it
    use strong controls and fresh confirmation where required
    reject or revise failures
    qualify survivors

A survivor may become current scoped authority.

Never erase how it became authority.
```
