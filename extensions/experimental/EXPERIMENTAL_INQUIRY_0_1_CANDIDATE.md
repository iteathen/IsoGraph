# IsoGraph Experimental Inquiry — 0.1 Candidate

**Status:** unqualified semantic/discovery extension candidate  
**Short name:** EI 0.1  
**Purpose:** generate lawful new observations under an explicitly incomplete experimental working model  
**Warrant dependency:** DP 0.10 Experimental Warrant at an exact qualified revision before EI promotion  
**Core dependency:** current qualified cumulative Core through 0.20  
**QU dependency:** qualified QU 0.1 whenever represented known-unknown structure is load-bearing  
**DTS dependency:** qualified DTS 0.1 whenever transition anatomy, path structure, or structural-event alignment is load-bearing  
**NEI dependency:** qualified NEI 0.4 only when identity is load-bearing  
**Growth rule:** creates no second graph substrate, no proof authority, no universal experiment language, no universal optimizer, no hidden probability distribution, and no permission for arbitrary parameter fishing

Experimental Inquiry consumes an evidence-backed Experimental Warrant and actively produces observations.

Its mission is:

> **Construct and revise an explicitly provisional experimental working model, discover an appropriate experiment space, generate lawful observations, preserve expected and unexpected structure, and return new evidence to the IsoGraph family.**

EI supplies evidence. It does not make its observations true by fiat and it does not admit semantic conclusions on behalf of Core, QU, DTS, NEI, or Discovery Protocol.

---

# 0. Constitutional barriers

Do not collapse:

```text
experiment
    != proof

observation
    != admitted assertion

working model
    != semantic authority

current scope
    != complete scope

current variables
    != complete dimensionality

current hypotheses
    != complete hypothesis set

expected output vocabulary
    != complete observation vocabulary

open-world reserve
    != QU realization

unexpected observation
    != noise

adaptive exploratory evidence
    != untouched confirmation

post-hoc alignment
    != pre-registered boundary

deferred dimension
    != excluded dimension

failure under tested scope
    != falsification outside coverage

experiment cost preference
    != correctness

random search
    != open-world inquiry
```

---

# 1. Input contract

EI requires an Experimental Warrant and the represented context needed to interpret it.

The warrant may be incomplete about the correct experiment space. That incompleteness is expected.

EI should recover, as applicable:

```text
active objective
anchors
parent clues / residuals / discrepancies
admitted implicit support
QU structure
DTS structure
scope evidence
known exclusions
deferred live dimensions
prohibited information sources
known or suspected outputs
open questions
reason new observations are warranted
```

EI must not convert absence from the warrant into exclusion.

---

# 2. Experimental working model

EI may construct an **experimental working model** containing provisional:

```text
candidate dimensions
interactions
controls
boundary events
candidate decompositions
candidate relations
candidate outputs
candidate observables
scope frontier
expected behaviors
open observation channels
```

The working model is discovery state.

It is not Core authority and does not become source truth merely because it successfully predicts an observation.

Every introduced element must retain a discovery rationale.

---

# 3. Scope discovery

EI owns active discovery of experimental scope.

It may:

- expand scope when residuals remain unexplained;
- narrow scope when evidence supports isolation;
- add controls required to interpret an intervention;
- test interactions when independent dimensions do not close;
- introduce gap-derived candidates when a structural role is missing;
- defer live dimensions without excluding them.

A scope transition should record:

```text
previous scope
new scope
rationale
evidence used
what became anchored / candidate / interaction / control / deferred / excluded
coverage consequences
```

No fixed bookkeeping vocabulary is semantically mandatory.

---

# 4. Three inquiry modes

## 4.1 Discriminating inquiry

Construct observations that separate already-live explanations.

## 4.2 Characterizing inquiry

Map dimensionality, boundaries, interactions, invariants, or response structure when the phenomenon is supported but undercharacterized.

## 4.3 Constructive / model-discovery inquiry

Propose and test lawful candidate bridges, decompositions, dimensions, couplings, or boundary structures when the represented pieces fail to close.

Constructive inquiry is not permission to invent arbitrary machinery. Every candidate must be recoverably gap-directed.

---

# 5. Experiment construction

A lawful experiment should record:

```text
parent warrant
purpose
working model revision
tested scope
deferred live scope
controls
intervention / variation
observation method
targeted observations
open observation channel
coverage claim
prohibited information sources
cost/valuation context if used
provenance
```

If a computation, simulator, solver, laboratory instrument, external dataset, or model generates observations, its revision and authority scope must be explicit.

```text
experiment generator output
    != automatically domain truth
```

The observation is evidence whose interpretation remains claim-relative.

---

# 6. Targeted and open observations

Every nontrivial EI experiment must permit both:

```text
targeted observations
    deliberately requested by the current working model

open observations
    structurally material behavior not anticipated by that model
```

EI must preserve material unexpected outputs instead of forcing them into expected categories.

Where practical, retain raw or reconstructable observation provenance so later model revisions can re-interpret the same run without losing information.

A summary that discards unexpected structure is not a sufficient experimental record when that structure may be load-bearing.

---

# 7. Model-breaking observations

An observation is model-breaking when the current working dimensions, QUs, interactions, or output vocabulary cannot represent it adequately.

EI should then:

```text
preserve the raw/reconstructable observation
mark the current model insufficient for that observation
reopen scope/model discovery
identify the smallest recoverable reason for expansion
avoid patching the observation into an existing category
```

A model break is not automatically a defect in the observation mechanism.

DP 0.8 discrepancy discipline remains applicable.

---

# 8. QU interaction

EI may consume QU topology and may generate evidence that:

```text
resolves a QU
refines a QU
characterizes a QU
discovers a missing constraint
tests an invariant across realizations
discovers coupling
identifies load-bearing portions
supports a scoped quotient
```

EI must not silently choose one QU realization.

Open-world model incompleteness remains separate from QU and must not be encoded by adding an unconstrained "anything else" realization to every QU.

---

# 9. DTS and structural-event alignment

EI may compare systems or trajectories at corresponding structural events rather than equal literal depth/time when the alignment has recoverable structural support.

Examples:

```text
same boundary discharge
same obligation closure event
same interface transition
same residual frontier
same structurally defined phase change
```

DTS supplies transition semantics where load-bearing.

EI records whether an alignment was:

```text
predeclared from warrant evidence
derived before observing the compared outcome
or discovered post hoc
```

Post-hoc alignments are legitimate discovery leads but must not masquerade as untouched confirmation.

---

# 10. Adaptive experimentation

EI is iterative:

```text
working model
-> experiment
-> observation
-> model revision
-> next experiment
```

Adaptation is allowed and expected.

However, each revision must retain lineage showing which observations selected the next variables, boundaries, controls, or hypotheses.

If later confirmation is required, use evidence not already consumed to select the tested structure, unless the governing claim explicitly permits adaptive evidence and accounts for it.

---

# 11. Negative results

Each experiment must define the scope it actually covers.

A negative result should record:

```text
parent clue
tested scope
coverage relation
specific candidate or consequence falsified
dimensions/interactions not covered
what remains live
```

EI must not promote:

```text
failed narrow probe
    ->
broad parent clue false
```

unless the probe was independently sufficient for the parent claim.

---

# 12. Observation return contract

EI returns evidence to the ordinary IsoGraph family.

Possible returns include:

```text
new observation
new residual
new invariant
new candidate dimension
new interaction
new boundary
new QU refinement evidence
candidate implicit assertion
candidate quotient
candidate transition correspondence
model inadequacy evidence
falsification within tested scope
confirmation within tested scope
```

Each return keeps experimental provenance and coverage.

Admission then routes normally:

- Core / Core 0.19 for exact support and implicit assertions;
- QU for structured unresolved possibility;
- DTS for transition anatomy;
- NEI for identity;
- DP for further discovery and warrants.

EI does not bypass those owners.

---

# 13. Anti-randomness and stopping

Open-world inquiry is not unrestricted search.

Continue an inquiry branch only while:

```text
material unresolved clue/gap remains
AND
next observation has a recoverable rationale
AND
the observation could materially distinguish or refine the working model
```

Stop, defer, or return unresolved when those conditions fail.

A parameter sweep may be lawful when its dimensions and coverage have a recoverable rationale. Mere availability of a parameter grid is not enough.

---

# 14. Valuation

If DP 0.9 is qualified and a valuation profile is supplied, EI may compare lawful experiments by declared costs or preferences.

Valuation occurs after experimental validity constraints.

```text
cheaper
    != more valid

smaller experiment
    != automatically better

largest coverage
    != automatically better
```

Do not invent weights or universal cost units.

---

# 15. Qualification targets

Before promotion, fresh blind qualification must test at least:

1. refusing to invent an experiment without a warrant;
2. discovering scope from partial clues;
3. selecting a narrow experiment only when narrowing is supported;
4. preserving interacting scope where required;
5. gap-directed candidate dimension generation;
6. QU use without realization selection;
7. open-world reserve without weakening QU;
8. targeted plus open observation recording;
9. preservation of unexpected output;
10. scope reopening after a model-breaking observation;
11. adaptive evidence lineage;
12. fresh-confirmation distinction after post-hoc selection;
13. structurally meaningful event alignment;
14. scope-limited negative interpretation;
15. anti-randomness stopping;
16. external generator provenance;
17. correct return routing to Core/IA/QU/DTS/NEI/DP;
18. cross-domain controls unrelated to the motivating Connect4 case.

---

# 16. Working summary

```text
A warrant says:
    new observations are justified.

EI asks:
    what lawful observation should be created next?

Build an explicitly provisional model.
Discover scope instead of assuming it.
Preserve unexpected structure.
Record adaptation.
Reopen the model when observations escape it.
Falsify only what coverage supports.
Return evidence, not truth.
```

EI 0.1 changes no current qualified authority until its exact revision and its dependency stack are independently qualified.
