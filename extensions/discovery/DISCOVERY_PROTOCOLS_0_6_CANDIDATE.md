# IsoGraph Discovery Protocols — 0.6 Candidate

**Status:** unqualified normative successor candidate  
**Short name:** DP 0.6  
**Base dependencies:** DP 0.1, DP 0.2, DP 0.3, DP 0.4, and DP 0.5  
**Core dependency:** current qualified Core 0.17 + Core 0.18 observation-first clarification  
**Identity dependency:** qualified NEI 0.4 only when a discovery conclusion actually relies on natural identity/distinctness  
**QU dependency:** qualified QU 0.1 whenever unresolved structure must be preserved or a downstream conclusion depends on the admissible realization family  
**Growth rule:** adds no Core relation, discovery status, identity result, anomaly ontology, mandatory search algorithm, or exhaustive search requirement

DP 0.6 is a narrow authority-routing correction over DP 0.5.

DP 0.5 was authored before NEI 0.4 became the current qualified Natural Entropic Identity authority. Its header therefore names the earlier cumulative NEI 0.1–0.3 successor chain.

DP 0.6 corrects that dependency:

```text
identity-dependent DP conclusion
    -> current qualified NEI 0.4 authority
```

rather than:

```text
identity-dependent DP conclusion
    -> historical / superseded NEI successor chain
```

All DP 0.1–0.5 discovery behavior remains in force unchanged.

---

# 0. Authority-routing barriers

Do not collapse these distinctions:

```text
Discovery Protocol priority
    != semantic proof authority

structural correspondence
    != NEI SAME

represented difference
    != NEI DISTINCT

identity-relevant discovery lead
    != identity conclusion

QU-bearing discovery structure
    != opaque UNKNOWN

qualified Core 0.18 observation-first semantics
    != automatic discovery success

qualified NEI 0.4 dependency
    != mandatory NEI invocation for non-identity discovery

qualified QU 0.1 dependency
    != mandatory QU materialization for determinate structure
```

---

# 1. Identity routing

When a discovery branch makes no natural/domain identity or distinctness conclusion, NEI is not required merely because objects, mappings, equivalences, or residuals are present.

When a discovery branch does make a natural/domain identity or distinctness conclusion, DP MUST route that conclusion through the current qualified NEI authority.

At this revision:

```text
current identity authority = NEI 0.4
```

DP itself never upgrades:

```text
structural match -> SAME
structural mismatch -> DISTINCT
```

without NEI authority.

---

# 2. QU routing

DP uses QU when unresolved structure is load-bearing for the discrepancy, comparison, identity evidence, quotient, or other downstream claim.

A determinate discovery case need not manufacture a QU state.

But:

```text
missing represented difference
    != proof no difference exists
```

and unresolved potentially load-bearing structure cannot be erased simply to close a discovery branch.

---

# 3. Core 0.18 routing

DP 0.6 depends on the qualified observation-first interpretation:

```text
observe
-> align quantity / predicate / scope / layer / authority / closure
-> preserve relevant unknowns and residuals
-> investigate bounded structural alternatives
-> classify when justified
-> repair only after defect ownership is established
```

DP 0.5's discrepancy-handling rules remain the discovery-specific realization of that Core discipline.

---

# 4. Qualification target

Before promotion, fresh qualification must demonstrate both:

1. the full DP 0.5 observation-first discovery behavior over new cases; and
2. correct current routing to Core 0.18, QU 0.1 and NEI 0.4 without importing those modules when a claim does not depend on them.

No historical DP qualification result is rewritten by this successor revision.
