# Experiment 050 — Fresh DP 0.8 principle-level holdout

## E01 — Offset writer
A binary format contract fixes offsets 0,4,8. A writer emits the correct three values at 4,8,12. Trace inspection proves the semantic values are correct before writing. Moving the write offsets to the contractual positions fixes every control; no other structure is implicated.

## E02 — Predicate connective
A source predicate is exactly A AND B. The implementation uses A OR B. The extra accepted cases vanish after the connective repair and no independent evidence supports the pattern formed by those cases.

## E03 — Cache-key collision and surviving quotient
Two distinct cache keys collide because one bit was omitted from hashing. Repairing the hash removes false cache hits. Independent exhaustive continuation testing still proves that a particular pair of states has the same future accepted suffix language.

## E04 — Scale-factor repair
One measurement adapter applies a factor of 100 instead of 10, violating its calibration contract. After correction, a cross-system normalized invariant that was approximate becomes exact under independently measured primitive quantities.

## E05 — Different quantities
One dashboard shows peak resident memory for the entire run. Another shows peak resident memory during parsing only. Both are correctly computed and labeled in their source APIs. A comparison tool subtracts them as if they were the same quantity.

## E06 — Scoped transducer equality
Two finite transducers have different provenance and internal states. Exhaustive testing proves identical outputs for every input in a declared finite interface scope. No natural-identity authority is supplied.

## E07 — Faithful source versus legacy expectation
A signed source record contains -17 and its checksum validates. IsoGraph reconstructs -17. An old expected-output file says +17 and has no provenance establishing precedence.

## E08 — Dropped sign
A trusted reference and two independent calculations contain -3x. A parser emits +3x after dropping the unary minus. Trace inspection locates that exact omission.

## E09 — Prestige conflict
A standards handbook says parameter q=4. A device-specific signed calibration file says q=5. Both are faithfully represented; no authority in scope says handbook prestige or age overrides the device calibration.

## E10 — Independent reference control
A source tuple, checksum, and independently generated reference all agree on relation R(a,b,c). The conversion emits R(a,c,b), and a converter trace shows argument slots 2 and 3 are swapped.

## E11 — Two faithful standards
Two standards are faithfully represented and both explicitly claim applicability to revision Z while specifying incompatible limits. No conflict-resolution authority is supplied.

## E12 — Missing closure authority
System A declares relation r transitive. System B gives several r tuples but neither declares completeness nor transitivity. The comparison asks whether B's r is transitive.

## E13 — Two QU realizations
A qualified QU object preserves two admissible mappings. Under one, a mismatch implies an index implementation defect; under the other, the compared outputs belong to distinct quantities and are expected to differ. No evidence chooses a realization.

## E14 — Finite agreement
Two samples agree on every property in a finite measured set. The measurement set is not complete for natural identity and no qualified identity theorem makes it sufficient.

## E15 — Dependency cone
A primitive edge incidence is proven reversed. Forty derived claims depend on it. Recomputing them is expensive, and a proposal keeps those claims unchanged after repairing the primitive edge.

## E16 — Motif after syntax repair
A malformed closing delimiter drops one row from a relation table. A dependency motif is observed before repair. After restoring the row, the same motif is exactly derivable from every row, including the restored one.

## E17 — Pattern after endian repair
A byte-order bug makes several unrelated values share a bit pattern. Correcting byte order eliminates the pattern in all independent controls; no remaining primitive relation supports it.

## E18 — Cross-domain recurrence
A lab workflow and a scheduler each contain explicit entry, recurrence, carried-state, and exit relations with an exact role correspondence. Their causal mechanisms and domain identities differ, and no common ontology is supplied.

## E19 — Search frontier view
A derived frontier summary is exactly reconstructible from existing primitive order/membership relations and speeds discovery. Deleting it leaves every exact claim reconstructable from primitive support.

## E20 — Corrupted row
One imported row creates a striking apparent correspondence. Integrity checks prove it is a duplicate corrupted row. Removing it under the established import contract eliminates the pattern, and fresh independent rows do not reproduce it.

## E21 — Green-test patch
A test expects 12 while implementation returns 13. No applicable source specification, oracle provenance, or contract has yet been located. A proposed patch changes a constant only because it makes the test green.

## E22 — Mixed case
An iterator skips the first element due to an established off-by-one defect. Repairing the iterator changes raw counts. Independently, after repair, two branches remain exactly equivalent under a complete continuation-language comparison even though their internal histories differ.
