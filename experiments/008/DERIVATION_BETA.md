# Derivation Beta

Use only the numbered steps below as source structure.

**B01.** Let (V) be a vector space of finite dimension (dge 1), let (T:V	o V) be linear, and choose a nonzero starting vector (v_0in V).

**B02.** Define the forward sequence by
[
v_{k+1}=T(v_k).
]
Consider the (d+1) generated vectors
[
v_0,v_1,ldots,v_d.
]

**B03.** A (d)-dimensional space cannot contain (d+1) linearly independent vectors. Therefore there is a nontrivial relation
[
a_0v_0+a_1v_1+cdots+a_mv_m=0
]
whose last nonzero coefficient is (a_m), with (1le mle d).

**B04.** Dividing by (a_m) and rearranging gives fixed coefficients (c_0,ldots,c_{m-1}) such that
[
v_m=c_0v_0+cdots+c_{m-1}v_{m-1}.
]

**B05.** Applying (T^s) to the relation in B04 preserves the same coefficients. For every (sge 0),
[
v_{m+s}=c_0v_s+c_1v_{s+1}+cdots+c_{m-1}v_{m-1+s}.
]

**B06.** This does not require later vectors to equal earlier vectors or to repeat in a cycle. The persistent constraint is a linear recurrence, not equality of states.

**B07.** The entire infinite forward sequence can therefore be reconstructed from finite information: the initial window
[
v_0,ldots,v_{m-1},
]
the coefficients (c_0,ldots,c_{m-1}), and the recurrence in B05.

**B08.** Hence every forward sequence generated by repeatedly applying one linear operator in finite dimension satisfies a finite linear recurrence.
