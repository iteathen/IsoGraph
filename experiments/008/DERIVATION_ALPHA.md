# Derivation Alpha

Use only the numbered steps below as source structure.

**A01.** Let (Q) be a finite set with (|Q|=nge 1), let (F:Q	o Q) be a deterministic map, and choose a starting state (q_0in Q).

**A02.** Define the forward sequence by
[
q_{k+1}=F(q_k).
]
Consider the (n+1) generated states
[
q_0,q_1,ldots,q_n.
]

**A03.** Only (n) different states are available, so among those (n+1) generated states there are indices
[
0le i<jle n
]
with
[
q_i=q_j.
]

**A04.** Determinism propagates that equality forward. For every (rge 0),
[
q_{i+r}=q_{j+r},
]
because applying the same iterate of (F) to equal states gives equal states.

**A05.** Put (p=j-i>0). Then for every (rge 0),
[
q_{i+r+p}=q_{i+r}.
]
Thus the part of the sequence beginning at (q_i) repeats with period (p).

**A06.** The states before (q_i) need not lie on that repeating block. They remain a finite prefix specific to the chosen start and map.

**A07.** The entire infinite forward sequence can therefore be reconstructed from finite information: the prefix
[
q_0,ldots,q_{i-1},
]
the block
[
q_i,ldots,q_{j-1},
]
and the rule that repeats the block.

**A08.** Hence every forward sequence generated by a deterministic map on a finite state set has a finite prefix followed by a repeating tail.
