## I. Summary of Core Rules and Interpretation Principles

As mandated by `CORE_SPEC_DRAFT_0_15_CONSOLIDATED_CANDIDATE.md`:
* **NAC Evaluation Separation:** The presence of a negative match condition (`!X`) does not imply execution or evaluation. `NAC object exists != NAC evaluated`. Evaluation requires a matcher/pattern/execution profile that explicitly defines the application boundary and active context.
* **Structural Multiset Rules:** Scopes are unordered but occurrence-preserving by default.
* **Variable Binding:** Variable identifiers (`?n`) must be owned by explicit binders (such as rules/patterns). Standalone variables without owners in closed propositions are invalid.
* **Profile-based Validation:** Active profiles dictate structural validity. Structural placements of NACs that violate target profile constraints result in profile-validation failures rather than ambient negative query execution.
