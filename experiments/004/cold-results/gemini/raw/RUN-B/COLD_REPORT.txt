## Ambiguity Report

Pursuant to the governing prompt, the following semantic and representation ambiguities are frozen and reported directly from the cold sources:

1.  **Implicit Argument Roles in Selection Records (`^4203`):** 
    The raw serialization syntax in `PHASE_B_REWRITE_CASES_004.axh` defines selection records using the stable label `^4203` as an ordered incidence (e.g., `(^4203 2003 2001 2002)`). From a strictly structural perspective, raw core syntax (Section 7, Section 15) does not privilege any argument position or define execution roles inherently. The mapping of these elements to `(application-event ID, state-object ID, rule-object ID)` relies entirely on the external semantic profile supplied by the governing prompt, demonstrating that raw labels remain downstream metadata (Section 2) and execution profile bindings must be explicitly agreed upon (Section 12.2).
    
2.  **Rule-Side Outer-Container vs. Outer Scope Wrapping:** 
    The rules are represented as `(^4202 2002 [[(10 ?0)] > [(30 ?0)]])`. The rewrite rule `[(10 ?0)] > [(30 ?0)]` is nested inside an outer scope bracket `[ ... ]` that acts as a structural container. A naive interpreter might collapse the outermost rule-side bracket with the container brackets. However, Draft 0.15 Section 12.1 clarifies that rule-side outer brackets are strictly pattern-splice boundaries, which resolves the ambiguity by distinguishing the rule's active boundary from the passive AXH scope wrapper.

3.  **Namespace Inheritance Across Disjoint AXH Top-Level Scopes:** 
    The input file `PHASE_B_REWRITE_CASES_004.axh` contains multiple, disjoint top-level scopes (Case `#2` and Case `#3`). The spec (Section 6.1, 6.2) notes that independent top-level documents do not share structural identity namespaces by default, but nested scopes inherit their enclosing namespace. Because Case `#2` and Case `#3` are evaluated independently as isolated test cases under different `#2` and `#3` selectors, the question of whether they share structural namespace is not load-bearing for this run, and identity hygiene is preserved.
