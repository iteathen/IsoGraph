# IsoGraph native-text file convention

Current native-text IsoGraph artifacts use the `.isg` extension.

Historical `.axh` files are retained as historical artifact names and remain recoverable exactly through Git history. They are not required to be mass-renamed merely to adopt the current project identity.

The extension is a repository/file-format convention only:

```text
.isg file extension
!= semantic revision
!= comparison view
!= primitive-status claim
```

The semantic authority of a native artifact comes from its pinned IsoGraph specification/profile/schema dependencies, not from its filename extension.
