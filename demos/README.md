# IsoGraph Demonstrations

This directory contains public, reproducible demonstrations of selected IsoGraph research applications.

A demonstration is an explanatory and reproducibility surface. It is **not** semantic authority, and its presence here does not promote a research finding into the IsoGraph Core or any qualified extension.

Current demos:

- [MIPLIB structural optimization](miplib-structural-optimization/README.md) — an exact active-symmetry discovery on the MIPLIB `n5-3` instance, mapped back to the original model and benchmarked under SCIP with replicated fresh-seed results and negative controls.

For semantic authority, use the versioned specifications and qualification manifests routed from the repository root.
