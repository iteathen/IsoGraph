## Purpose

Qualify whether an isolated reasoner can decide when new observations are warranted without converting the warrant into hypothesis support, complete scope, a QU realization, or arbitrary experimentation.

## Freeze and isolation

Before semantic execution freeze candidate bytes, predecessor/dependency hashes, public cases, public schema, hidden assertions, case order, and provider/model policy.

The cold packet must exclude hidden expected values, issue #60, motivating Connect4 results, prior candidate outputs, scorer source, repository status summaries, and any description of the intended answer beyond the public case facts.

## Required case families

Use fresh cross-domain cases covering:

1. represented closure -> no warrant;
2. partial coherent clue -> warrant;
3. QU topology clue without realization choice;
4. detailed QU plus open-world reserve;
5. incomplete variable set requiring scope discovery;
6. justified narrow intervention;
7. interacting clue where narrow probe is insufficient;
8. deferred dimension not excluded;
9. gap-derived candidate experimental direction;
10. model-breaking unexpected observation requiring reopened scope;
11. narrow negative result with limited coverage;
12. structural-event alignment;
13. post-hoc alignment requiring provenance/fresh confirmation;
14. adaptive evidence not reused as untouched confirmation;
15. random parameter-grid temptation rejected;
16. warrant without hypothesis-truth claim;
17. DTS-sensitive warrant routing;
18. NEI-sensitive boundary;
19. no warrant where new observation cannot materially change the model;
20. cross-domain anti-overfit composition.
