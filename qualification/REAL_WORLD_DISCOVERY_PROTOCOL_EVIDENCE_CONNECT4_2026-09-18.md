## Observed outcomes

### 1. Hidden distinction established

The campaign established that:

```text
explicit scope metadata presence
    !=
semantic validity restriction
```

The triggering decoder outputs were wrong for the requested mechanical field, but the discrepancy exposed a real difference between representation metadata and proposition-level semantic scope.

### 2. Evidence identity staircase exposed

For Connect4 claim C4-R0045, the campaign recovered:

```text
4 claim citations
4 distinct source artifacts
3 evidence events
2 evidence lineages
cross-lineage independence UNKNOWN
```

The cold decoder's wrong source count was `3`, which exactly equals the represented event count.

The campaign therefore established the 4/4/3/2 hierarchy and retained only a **supported candidate** that the decoder substituted the event layer for the requested source/citation layer. It did not claim access to the model's hidden internal reasoning.

This is a useful adversarial fixture for future evidence-identity qualification.

### 3. Property ownership/layer distinction established

The campaign established that empirical-independence applicability in the represented evidence model belongs to evidence lineage/proof topology rather than to claim epistemic status alone.

A claim-status-only derivation was falsified.

### 4. Attractive quotient hypothesis falsified

Three relation-count discrepancies all had the form `actual - 1`.

The campaign tested several tempting common explanations:

- omit `supports`;
- count unique relation types;
- count claim-ID targets only;
- collapse reciprocal dependency/support edges.

No candidate explained all three cases.

The shared minimal-generating-basis interpretation was therefore rejected rather than promoted merely because the numerical pattern looked suggestive.

### 5. Ordinary error correctly closed

The cold prose substitution:

```text
13 evidence lineages
```

versus:

```text
10 lineages
13 events
```

required no new structural layer because authority 1.1 already represented the distinction explicitly.

The branch closed as ordinary summarization substitution.

## Cross-case synthesis

The Connect4 run produced a supported recurring shape:

```text
requested observation at semantic layer L
    ->
observer returns nearby projection / aggregation / inferred layer L'
    ->
answer is meaningful in the represented system
    but wrong for the requested contract
```

This motivates treating an observation as a typed coordinate including at least:

```text
subject
predicate / quantity
representation layer
aggregation level
scope / view
authority revision
closure assumptions
value
```

Core 0.18 already proposes this alignment discipline. The Connect4 campaign supplies concrete non-synthetic evidence for it.

## Protocol-value evidence

The campaign yielded all major outcomes a useful discovery method should support:

```text
real hidden structure found
plausible candidate retained but not overclaimed
attractive false pattern falsified
ordinary error closed
unknown/residual preserved

```

This is especially relevant because the protocol did **not** optimize toward finding an isomorphism.
